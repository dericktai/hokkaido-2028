3167 大量科技｜零基礎圖解

看懂 PCB、CPO，以及大量真正賺錢的地方

一句話：大量不是只賣「鑽孔機」，而是在 AI Server 高階 PCB 與 CPO 精密製程中，賣更高單價的量測、定位、鑽孔與成型設備。

① 先懂 PCB 與 CPO

🛣️ PCB = 電子產品裡的多層高速公路

PCB（Printed Circuit Board）負責讓晶片、記憶體、網路晶片彼此連線。AI Server 的資料量越大，PCB 層數越多、訊號越快，孔深與線路精度要求也越高。

AI GPU→高速 PCB→鑽孔 / 背鑽 / 成型

💡 CPO = 把光引擎靠近運算晶片

CPO（Co-Packaged Optics，共同封裝光學）把光學元件放到交換器 ASIC 附近，減少高速電訊號長距離傳輸。越到 1.6T、3.2T，對板材與成型精度越嚴格。

交換器 ASIC⇄光引擎→光纖

② 大量的兩大事業

🏭 事業一：PCB 精密設備

Drill 鑽孔機：在 PCB 上鑽導通孔。

Back Drill 背鑽：把不需要的 Stub 殘段鑽掉，降低高速訊號反射。

TM4 StubMapper：先量出內層位置與深度，再讓鑽孔機精準下刀。

Premium CCD Router：用相機定位後精密切割 PCB 外形；1.6T / CPO 需要更高精度。

🔬 事業二：半導體 AOI / Metrology

由 大量先進智能 TLSmart 發展，切入 CoW、SoIC、FOPLP / CoPoS、CPO 等先進封裝。

AOI：Automated Optical Inspection，自動光學檢查。

Metrology：精密量測，例如翹曲、高度、偏移。

現階段營收占比仍較小，但提供未來跨入半導體設備的第二成長曲線。

③ 為什麼 AI Server 讓大量賺得更快？

112G → 224G SerDes→訊號更敏感→Stub 要更短→背鑽精度提升→TM4 + CCD Drill

SerDes 是高速串列傳輸介面。速度越高，PCB 裡殘留的小段銅孔就越容易造成反射與訊號品質問題，因此量測與背鑽變得更重要。

⑤ CPO 對大量的意義

800G 光模組成型精度大約在 <50 μm 等級；往 1.6T / CPO 發展，大量主打的 Premium CCD Router 精度可做到 <25 μm。

800G→1.6T→CPO→更高精度 Router

所以 CPO 對大量不是單純概念股題材，而是直接提高「切割 / 成型精度」門檻，讓 Premium Router 的價值上升。

⑧ 風險：不是單一客戶，但有中國集中

🟢 單一客戶風險相對較低

需求來自多家大型 PCB 與半導體製造客戶，不是只綁一個 GPU 或雲端品牌。

🟠 區域集中風險高

2025 區域營收約：中國 68.7%、東南亞 21.7%、台灣 9.6%。

所以要追蹤中國 PCB 資本支出、價格競爭、美中科技管制與客戶東南亞移轉。
