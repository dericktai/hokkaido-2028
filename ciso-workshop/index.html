02 / CISO Closed-door Workshop

四大產業分組：每組兩題，聚焦「成熟度落差＋下一步行動」

金融

問題一｜治理門檻
AI / Agent 接觸客戶資料、交易流程與內部知識庫後，最大門檻是資料、權限、第三方模型、法遵，還是責任歸屬？

問題二｜上線底線
未來 12 個月若 Agent 必須正式上線，哪些控制屬於「沒有就不能上線」？請排前三項。

製造

問題一｜看不見的風險
AI 進入研發、工程、產線與供應鏈後，最大盲點是 Shadow AI、研發資料外洩、第三方 AI、OT/IT 邊界，還是 Agent 權限？

問題二｜創新與安全
如何不阻礙工程創新，又能把 AI 從「員工自行使用」推進到「企業可控使用」？

高科技

問題一｜研發環境
Coding Agent、RAG、LLM 與外部 AI 工具進入研發流程後，最難保護的是 Source Code、Credential、IP、模型供應鏈，還是 Agent 行為？

問題二｜Agent 權限
當 Agent 可以讀檔、改 Code、呼叫 API 與執行指令，哪些行動一定需要最小權限或 Human-in-the-Loop？

其他

問題一｜有限資源
醫療／流通／服務業 AI 應用增加，但資安資源有限時，最大的治理斷層在哪裡？

問題二｜最小基線
若不能一次建立完整 AI Governance，最小可行的 AI Security Baseline 應先包含哪三項？

預期：各組產出 2–3 項最重要 AI Security Gap3 / 7

我們要觀察的成熟度落差

企業可能已進入 Level 2–3 的 AI Adoption：有政策、有 PoC、有部分技術控制；但 Agent Identity、Runtime Monitoring、AI IR、Kill Switch 等仍停留在 Level 1–2。

最後要帶出的管理問題

如果 AI 導入成熟度已到 Level 3，但 AI Security 還在 Level 1，你未來 12 個月最先補哪一項？

06 / Final Message

整場 CISO 年會要傳達的核心結論

AI Adoption 已經進入下一階段，
但多數企業的 AI Security Governance 並未同步升級。

真正的風險，不只是 AI 本身，而是 AI 已取得資料、身分與執行能力後，企業仍沿用過去以「人」為中心的治理制度。

CISO 閉門工作坊

找出問題：各產業成熟度落差在哪裡？未來 12 個月最先補什麼？

贊助商工作坊

拆解問題：從使用治理、威脅、資料、Agent Control 到制度化治理，形成完整解法路徑。
